# Itinérance et usage à l’étranger NovaTel

> Zones, enveloppes et procédures d’exemple entièrement fictives. Ne pas les utiliser pour planifier un vrai voyage ou une dépense.

## Enveloppe simulée

Dans le scénario NovaTel, le forfait Mobile Plus comprend jusqu’à 25 Go dans la zone Europe définie par le contrat fictif et Mobile Max jusqu’à 40 Go. Mobile Essentiel n’inclut aucune enveloppe d’itinérance décrite dans cette base. Les appels, SMS, destinations et pays couverts ne sont pas détaillés ici ; Nova ne doit donc pas garantir leur inclusion.

## Hors zone ou enveloppe inconnue

Avant un voyage, le client doit vérifier les conditions et options affichées sur son contrat. La base NovaTel ne fournit aucun tarif pour le Canada ou les autres destinations hors zone. Nova ne doit pas inventer de prix ni de frais ; elle propose de vérifier auprès d’un conseiller.

## Activation

Le téléphone doit autoriser l’itinérance des données si le client souhaite utiliser les données mobiles hors de son pays. Cette action peut entraîner des frais selon un contrat réel ; l’agent rappelle de vérifier les conditions du fournisseur avant activation.
