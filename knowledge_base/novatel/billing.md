# Facturation NovaTel

> Règles de facturation inventées pour le prototype NovaTel ; elles ne décrivent pas les pratiques d’un opérateur réel.

## Émission et lecture d’une facture

Dans la simulation, la facture est publiée le 12 de chaque mois dans l’espace client, rubrique « Factures ». Le prélèvement automatique est programmé cinq jours après l’émission. Une facture présente le forfait, les options activées, les éventuels frais ponctuels simulés et les ajustements de période. Nova n’a pas accès aux factures personnelles et ne peut pas déterminer la cause réelle d’un montant.

## Montant inhabituellement élevé

Comparer le montant au forfait, vérifier les options ajoutées, les achats ponctuels, les usages hors enveloppe et les proratas lors d’un changement d’offre. Ces éléments sont des pistes générales issues du scénario NovaTel, pas le diagnostic d’un compte. La base ne fournit pas de frais précis au-delà des tarifs affichés dans les fiches d’offres.

## Contester une ligne

Dans le parcours fictif, ouvrir la facture, choisir « Signaler une ligne », puis indiquer la ligne concernée et le motif. Un conseiller doit examiner les justificatifs et confirmer la suite. Nova ne peut ni consulter la facture, ni ouvrir une contestation, ni promettre son issue.
